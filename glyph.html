SIEMENS DIGITAL INDUSTRIES SOFTWARE • 2024—2025

Turning 10,000+ scattered enterprise icons into instant conversational discovery.

At Siemens DISW, enterprise designers and engineers wasted hours hunting for standardized glyphs across fractured repositories. We conceptualized and designed Glyph—a Copilot-native conversational agent using vector semantic embeddings, context-aware token resolution, and live Figma/IDE injection to slash retrieval time by 74% with an 81.07 SUS score.

Role Lead AI Product Designer
Team 1 PM, 4 ML/Fullstack Eng, 2 DS Leads
Timeline 5 Months (Discovery to V1 Pilot)
Key Metric 81.07 SUS • 74% Time Saved
The Problem Space

The vocabulary gap between design and code.

In complex industrial automation software, a simple component like a "shutoff valve" has 18 distinct variations depending on whether it’s hydraulic, pneumatic, motorized, or fail-safe.

Designers searched visually using real-world physical metaphors ("emergency red handle"), while frontend engineers searched by internal token nomenclature ($sys-actuator-emergency-24).

CRITICAL INSIGHT

42% of icon searches failed because people were searching for intent and purpose ("indicates sensor offline") rather than literal taxonomy.

EDGE CASE ARCHITECTURE

Graceful handling of polysemy and industrial ambiguity.

In factory software, generic words like "power" or "status" cause destructive misunderstandings if an agent guesses wrong. We designed explicit confirmation micro-dialogues into the conversation loop.

AMBIGUOUS INTENT DISAMBIGUATION USER QUERY: "POWER"

Instead of returning a random grab-bag of lightning bolts and switches, Glyph parses the active project domain and prompts the user with crisp tactile chips:

1. Electrical Wattage & High Voltage GRID SPEC
2. System Power State / On-Off Toggle HMI CONTROL
3. Mechanical Motor Output (Torque / HP) DRIVE SYSTEM
DESIGN-TO-CODE SYNCHRONIZATION OUTPUT FIDELITY

When an engineer selects a glyph in VS Code, Glyph injects the official npm package import and SCSS design token rather than an unstyled raw SVG string:

import { IndustrialActuatorIcon } from '@siemens/glyph-icons-react';

<IndustrialActuatorIcon
  size="24"
  variant="telemetry-active"
  theme="dark"
/>
CANDID REFLECTIONS • LESSONS LEARNED

Designing for trust in enterprise generative tooling.

When we first launched the alpha version, users were hesitant because AI search results felt opaque—they didn’t know why an icon had been surfaced or whether it adhered to Siemens’ strict accessibility standards (WCAG AAA).

We solved this not with more LLM cleverness, but with radical transparency: every recommendation showed its cosine similarity score, token lineage, and direct Figma library link. Trust returned the moment users felt the system wasn't "guessing," but merely accelerating their own judgment.

The project taught me that the real art of AI product design isn't generating answers—it's building the guardrails, ergonomics, and latency tolerances that make autonomous tools reliable in mission-critical environments.
